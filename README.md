# Our Ballot 45209

An independent, nonpartisan voter guide to everything on the **November 3, 2026** general election ballot in Cincinnati ZIP code 45209 (Hamilton County, Ohio).

**Live site:** https://dwillcode.github.io/ballot-guide-45209/

## What's in it

- Every contest in roughly ballot order: statewide offices, Ohio Supreme Court, U.S. Senate, U.S. House District 1, state legislature, county offices, local judges, and ballot issues.
- Each candidate gets the same sections: background, stated positions, and record, with a numbered source on every point.
- Side-by-side issue comparisons for the governor, U.S. Senate, U.S. House and County Commission races.
- Cincinnati Bar Association survey ratings for every judicial candidate.
- Plain-language YES/NO explanations and costs for State Issue 3, the Cincinnati Public Schools levy and County Issue 10.
- A household checklist that points to the contests that affect you most, and a copyable cheat sheet for the polls.

## Design principles

- **Nonpartisan:** no party colors, alphabetical order within each race, identical sections for every candidate.
- **Sourced:** if a source didn't cover a topic, the guide says so instead of guessing. Sources were checked October 13, 2026.
- **Accessible:** large type with a three-step text-size control, a typeface designed for low vision, high contrast in light and dark mode, keyboard support, and text alternatives for every chart and photo.
- **Private:** no accounts, tracking or analytics. Choices you mark are saved only in your own browser.

## Corrections and photos

Spot an error, or own a photo and want it removed? Please [open an issue](https://github.com/dwillcode/ballot-guide-45209/issues).

Candidate photos are credited on each card and belong to the candidates, campaigns, or organizations noted (WVXU, Ballotpedia, and the Cincinnati Bar Association).

## Running it locally

It's a single static file. Open `index.html` in a browser, or serve the folder with any static server.
